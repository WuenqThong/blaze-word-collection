# Frontend — Blaze Voice Collection

React 19 + TypeScript + Vite. Cổng dev: **7777**.

```bash
npm install
cp .env.example .env   # VITE_API_BASE_URL=http://localhost:8765/api
npm run dev            # dev server
npm run build          # type-check (tsc -b) + build ra dist/
npm run lint
```

Cấu trúc `src/`, route và quy ước code: xem [docs/ARCHITECTURE.md §5](../docs/ARCHITECTURE.md#5-frontend) và [docs/DEVELOPMENT.md](../docs/DEVELOPMENT.md).
